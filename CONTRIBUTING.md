# Contributing Guidelines

Thank you for your interest in contributing to this portfolio project!

## How to Contribute

1. **Fork the repository** to your own GitHub account.
2. **Clone the project** to your local machine.
3. **Create a branch** locally with a descriptive name (`git checkout -b feature/my-awesome-feature`).
4. **Make your changes** to the code.
5. **Commit your changes** with a descriptive commit message (`git commit -m "Add some feature"`).
6. **Push your branch** to GitHub (`git push origin feature/my-awesome-feature`).
7. **Open a Pull Request** in this repository.

## Development Setup

This project uses Next.js and npm. To get started locally:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

## Style Guidelines

- This project uses CSS Modules for styling (`.module.css`).
- Please ensure new code follows the existing formatting.
- Avoid introducing breaking changes to the core UI/UX structure without discussing it in an issue first.
