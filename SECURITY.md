# Security Policy

## Supported Versions

Currently, only the `main` branch of this repository is actively maintained for security updates.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an e-mail to the project owner at `hrmpathum21@gmail.com`. All security vulnerabilities will be promptly addressed.

Please do not disclose security-related issues publicly until a fix has been released.
